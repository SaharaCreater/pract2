# Dependency Graph Visualizer (Variant 25)

Инструмент командной строки на чистом Python для анализа и построения графа зависимостей пакетов Ubuntu (apt).

## Возможности
1. **Парсинг конфигурации**: чтение параметров из файла `config.yaml`.
2. **Анализ прямых зависимостей**: извлечение информации о зависимостях заданного пакета.
3. **Построение полного графа**: рекурсивный обход в ширину (BFS) с ограничением максимальной глубины (`max_depth`) и корректной обработкой циклов.
4. **Режим тестирования**: поддержка загрузки графа из текстового файла (`test_graph.txt`) с условными обозначениями пакетов.
5. **Обратные зависимости**: расчет и вывод реверсивного графа (какие пакеты зависят от текущего).
6. **Визуализация**: опциональный вывод структуры в виде ASCII-дерева в консоль (`ascii_tree`).

## Требования
* Python 3.8+
* PyYAML

## Структура проекта
* `src/main.py` — основной исполняемый файл приложения.
* `config.yaml` — файл конфигурации параметров запуска.
* `test_graph.txt` — тестовый файл графа для режима тестирования.
* `run.sh` — скрипт быстрой сборки и запуска.
* `tests/` — директория для тестов.

## Конфигурация (`config.yaml`)
Пример параметров:
```yaml
package_name: "A"
repository_url: "test_graph.txt"
test_mode: true
package_version: "1.0.0"
output_image: "graph.png"
ascii_tree: true
max_depth: 3
```
## Запуск
```
./run.sh
